# 🏋️ Iron Clan Fitness Studio — Official Website

> A modern, responsive fitness studio website built for **Iron Clan Fitness Studio, Banashankari, Bengaluru**, designed to provide visitors with an immersive digital experience of the gym, its training programs, facilities, membership options, reviews, and contact information.

---

## 📌 Project Overview

**Iron Clan Fitness Studio** is a modern fitness studio website created to provide a professional digital presence for a local fitness business.

The website allows visitors to explore the studio, learn about its training programs, view facilities and gallery content, explore membership options, experience an interactive 360° studio view, read customer reviews, and contact the fitness studio.

This project was developed using **AI-assisted development** and then configured as a local development project using **React, TypeScript, Vite, and Node.js**.

The project is available on GitHub as a **source-code portfolio project** and is designed to be cloned and run locally by other developers.

---

## 💡 Problem Statement

Many local fitness studios rely heavily on social media and word-of-mouth to reach potential customers.

This project demonstrates how a professional website can provide a centralized digital presence where visitors can:

- Discover the fitness studio
- Understand its training programs
- Explore facilities
- View images and the studio environment
- Check membership options
- Read customer reviews
- Find the studio location
- Contact the business easily
